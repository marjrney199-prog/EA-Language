# Contribuir

Obrigado por melhorar a EA Language Hub.

1. Abra uma issue para alterações relevantes.
2. Crie branch `feat/nome`, `fix/nome` ou `docs/nome`.
3. Instale com `npm ci` e nunca edite `package-lock.json` manualmente.
4. Mantenha TypeScript estrito, componentes acessíveis e textos traduzíveis.
5. Execute `npm run typecheck`, `npm test` e `npm run build`.
6. Commits devem seguir Conventional Commits.
7. O pull request deve explicar problema, solução, testes, riscos, screenshots e impacto em acessibilidade.

Não inclua segredos, dados pessoais, conteúdo proprietário ou dependências sem licença compatível. Alterações de autenticação, pagamentos e uploads exigem revisão de segurança.
