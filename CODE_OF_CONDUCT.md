# Código de Conduta

Comprometemo-nos a uma comunidade aberta, acolhedora e livre de assédio. Seja respeitoso, aceite feedback, preserve a privacidade e considere diferenças linguísticas, culturais e de capacidade.

Comportamento abusivo, discriminatório, sexualizado, ameaçador ou divulgação de dados privados não será tolerado. Incidentes podem ser reportados confidencialmente para conduta@ealanguagehub.com. A equipa pode remover conteúdo, restringir participação ou banir participantes, de forma proporcional e documentada.
